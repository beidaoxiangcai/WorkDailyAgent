# DeepSeek API Key 设置 PRD

## 1. 需求目标

用户无需在 CLI 启动应用前配置环境变量，即可在设置页安全配置 DeepSeek API Key 并生成日报。

本期固定使用 DeepSeek，不提供服务商或模型选择。

## 2. 功能范围

### 2.1 本期范围

- 设置页新增 DeepSeek API Key 输入入口。
- 密码形式输入，支持显示或隐藏本次输入内容。
- 保存前向 DeepSeek 发起最小请求验证 Key。
- 验证成功后保存到 macOS Keychain，只展示末四位。
- 支持替换或移除 Keychain 中的 Key。
- 保留 `DEEPSEEK_API_KEY` 环境变量作为开发兼容入口。
- 未配置 Key 时点击生成日报，弹出配置提醒。
- 提醒的主操作为“去设置”，点击后跳转设置页并聚焦 API Key 输入框。

### 2.2 非本期范围

- 服务商和模型选择。
- 应用内申请、充值或管理 DeepSeek 账号。
- 自动重试生成或配置成功后自动补生成。
- 未配置 Key 场景的 Toast 提示。

## 3. 页面与交互

### 3.1 设置页

“DeepSeek API Key”区域展示：

- 配置状态：未配置、已配置 `····1234` 或由环境变量提供。
- API Key 密码输入框。
- “显示”复选框。
- “保存并验证”按钮。
- Keychain 配置存在时展示“移除密钥”。

完整 API Key 保存后不再回显。验证失败时保留输入，显示可理解的页内错误；验证成功后清空输入并显示成功反馈。

### 3.2 生成日报

```text
点击生成日报
  → 后端检查 Keychain 和环境变量
  → 未配置：弹出提醒
  → 点击“去设置”
  → 跳转设置页、滚动到配置区并聚焦输入框
```

用户点击“取消”时关闭提醒并留在当前页面，不显示 Toast。

## 4. 安全与隐私

- Keychain 优先于环境变量。
- 完整 Key 不写入 SQLite、配置文件、前端本地存储或日志。
- 后端状态接口只返回是否配置、来源和末四位。
- 服务商原始错误响应体不写日志，也不返回前端。
- Key 仅在前端本次输入、Tauri IPC 和 Rust 请求内存中短暂存在。
- 界面说明日报时间线会发送给 DeepSeek 处理。

## 5. 状态与提示

| 场景 | 用户反馈 |
|------|----------|
| 未配置 Key | 弹窗提示，主操作“去设置” |
| 保存并验证成功 | 页内提示“API Key 已保存并验证” |
| Key 无效 | 页内提示检查 API Key |
| 余额不足 | 页内提示账户余额不足 |
| 请求过于频繁 | 页内提示稍后重试 |
| 网络或服务异常 | 页内提示检查网络或稍后重试 |

## 6. 验收标准

1. 不设置环境变量时，可在设置页保存有效 Key 并生成日报。
2. 无效 Key 不写入 Keychain，也不覆盖原有有效 Key。
3. 完整 Key 不会由状态接口回传，也不会出现在数据库和日志中。
4. 未配置 Key 点击任一“生成日报”入口，均弹出相同提醒。
5. 点击“去设置”后输入框进入视口并获得键盘焦点。
6. 未配置 Key 场景不显示 Toast。
7. 用户可替换或移除 Keychain 中的 Key，环境变量兼容逻辑保持可用。
