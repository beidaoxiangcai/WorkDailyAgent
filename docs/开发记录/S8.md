## 4. 已知边界

- GitHub 仓库可安装不等于自动进入公共 Skill 搜索目录，可搜索性需另行发布。
- 仅支持 macOS，首次启动仍需下载 npm/Rust 依赖并由用户授予辅助功能权限。
- 应用未运行时，当天当前尚未闭合的活动不在 SQLite 中，CLI 会显式标记该降级。
- 自定义模板需遵循 `schema_version=1` 和单一数据占位符契约。
- 多日离线轨迹是包含 `index.html`、`assets/` 和 `data/` 的完整目录，不是单个自包含 HTML；归档时不能只复制首页。
- 用户主动“全部展开”长时间范围时，浏览器仍会逐日加载全部明细。
- 受控浏览器的 URL 安全策略禁止访问本地 `file://` HTML，因此未执行真实点击和截图验收；HTML 生成、范围折叠配置、每日数据注册和脚本转义由自动化测试覆盖。
