### 2.2 关键代码变更

**`merger.rs`（新增）— 合并引擎状态机**

核心数据结构：
- `RawEvent`：采集原始事件（ts / app / bundle_id / pid / window_title）
- `MergedEvent`：合并后闭合事件（app / bundle_id / window_title / start_ts / end_ts / duration_ms）
- `ActiveEvent`：正在跟踪的事件（内部状态，含 start_ts / last_ts）
- `Merger`：状态机，维护 `current`（当前事件）+ `prev`（上一个事件，用于去抖动）+ `completed`（待 flush 缓冲）

状态机逻辑（`on_event`）：
1. **空闲检测**：系统空闲 > 300s → 闭合 current（end_ts 修正为 `now - idle_secs`），进入 idle 状态
2. **同一 app+title**：更新 current.last_ts（累加时长）；若 prev 存在且去抖动窗口已过（>3s），闭合 prev
3. **应用切换 + 去抖动**：若 raw 匹配 prev（A→B→A）且 B 持续 ≤3s → 丢弃 B，恢复 A 为 current
4. **正常切换**：闭合 prev（如有），current 移入 prev，开启新 current

**`storage.rs`（新增）— SQLite 存储**

- `Storage::open(path)`：打开数据库，`PRAGMA journal_mode=WAL` + `synchronous=NORMAL`，自动建 events / blacklist 表
- `Storage::insert_events(&[MergedEvent])`：事务包裹批量 INSERT，失败整体回滚
- 表结构严格按技术方案 v1.3：events（id/start_ts/end_ts/app/bundle_id/window_title/duration_ms/category/source/created_at）+ blacklist（id/bundle_id/app_name/created_at）

**`collector/macos.rs` — 新增系统空闲时间**

```rust
#[link(name = "CoreGraphics", kind = "framework")]
extern "C" {
    fn CGEventSourceSecondsSinceLastEventType(stateID: u32, eventType: u32) -> f64;
}

pub fn get_system_idle_secs() -> f64 {
    // kCGEventSourceStateHIDSystemState = 1, kCGAnyInputEventType = 0xFFFFFFFF
    unsafe { CGEventSourceSecondsSinceLastEventType(1, 0xFFFFFFFF) }
}
```

> 使用系统真实空闲时间（自上次键盘/鼠标输入），比"同窗口 5 分钟未变"更准确：用户活跃工作时不会误判离开，用户离开后能精确闭合事件。

**`collector/mod.rs` — 重写为数据管线**

- `Collector::new(storage)`：接收 Storage 实例，内部创建 Merger
- `run()`：`tokio::select!` 驱动双定时器
  - 3s tick → `poll_once()` 产出 RawEvent → `merger.on_event(raw, idle_secs)`
  - 10s tick → `merger.drain_completed()` → `storage.insert_events()` 批量写入
- `poll_once()` 返回 `Option<RawEvent>`（黑名单命中 / 读取失败返回 None）

## 4. 遇到的问题与解决

### 4.1【环境·低】rsproxy 下载 zerocopy 超时

- 现象：首次 `cargo check` 下载 `zerocopy` 时 rsproxy 镜像传输超时（30s 0 bytes）。
- 解决：重试一次即成功。rsproxy 偶发慢速，不影响后续编译。

### 4.2【设计决策】空闲检测用系统空闲时间而非"窗口未变"

- 技术方案原文：`当前事件持续 > 5 分钟且 app+title 未变 → 判定离开`
- 问题：用户活跃工作于同一窗口 5 分钟也会被误判离开。
- 改进：改用 `CGEventSourceSecondsSinceLastEventType` 获取真实系统空闲时间（自上次键鼠输入）。用户活跃工作时 idle_secs 接近 0，不会误判；用户离开后 idle_secs 持续增长，超 5min 精确闭合。end_ts 修正为 `now - idle_secs`（最后一次实际活动时间），duration 更准确。
- 验收项"不动鼠标键盘 6 分钟 → 事件闭合"由系统空闲时间直接保证。
