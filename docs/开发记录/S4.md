## 2. 具体变更

### 2.1 项目结构

```
code/src-tauri/src/
├── lib.rs              # +generate_daily_report +get_reports 命令 + today_str/civil_from_days
├── storage.rs          # +reports 表 + ReportRow + save_report + get_reports
└── generator.rs        # 【新增】日报生成：Prompt 组装 + DeepSeek 调用 + 降级模板

code/src/
├── App.tsx             # +ReportsPage 组件 + 顶栏生成按钮
└── App.css             # +日报页样式（Tab/卡片/复制按钮）
```

### 2.2 关键代码变更

**`generator.rs`（新增）— 日报生成模块**

- `generate_daily_report(events)` → `GeneratedReport { content, llm_model }`
- `build_timeline(events)`：事件列表 → 时间线文本（`10:02 VS Code - xxx.java (18min)` 逐行）
- `call_deepseek(timeline)`：reqwest POST `https://api.deepseek.com/chat/completions`，OpenAI 兼容协议
  - API Key 从 `DEEPSEEK_API_KEY` 环境变量读取
  - model = `deepseek-chat`，temperature = 0.3
  - 系统提示词按技术方案 v1.3：`你是一个工作日报助手...按项目或时间组织，2~5 条`
  - 30 秒超时
- `fallback_template(events)`：LLM 失败/无 Key 时降级，输出 `【今日完成】` + 应用名+时长列表

**`storage.rs` — reports 表**

表结构（按技术方案 v1.3）：
```
reports(id, type, period_date, generated_at, content, event_ids, llm_model)
```
- `save_report(type, period_date, content, event_ids, llm_model)` → 插入并返回 id
- `get_reports(type, period_date?)` → 按生成时间倒序返回，可选日期筛选
- `ReportRow`：serde::Serialize，`type` 字段用 `#[serde(rename)]` 避免关键字冲突

**`lib.rs` — Tauri 命令**

- `generate_daily_report()`（async）：查当日事件 → `generator::generate_daily_report` → `save_report` → 返回内容
  - 无事件时返回错误提示
  - event_ids 存为 JSON 数组字符串
- `get_reports(report_type, date?)`：透传 storage 查询
- `today_str()` + `civil_from_days()`：用 Howard Hinnant 算法在 UTC+8 时区下算今日日期字符串，避免引入 chrono

**前端 — 日报/周报页 + 生成按钮**

- 顶栏新增"生成今日日报"按钮（紫色主色），生成中显示"生成中…"并禁用
- 生成完成后自动跳转日报页
- `ReportsPage` 组件：
  - 双 Tab（日报/周报）切换，激活态下划线高亮
  - `invoke('get_reports', { reportType })` 查询列表
  - 卡片：日期+生成时间 + 模型标签（如 `deepseek-chat`，降级时不显示）+ 复制按钮 + 内容预览
  - 复制：`navigator.clipboard.writeText`，复制后按钮变"已复制"2 秒
  - 空列表提示"点击顶栏生成今日日报创建"

### 2.3 依赖变更

- `Cargo.toml`：新增 `reqwest = { version = "0.12", features = ["json", "rustls-tls"], default-features = false }`
  - rustls-tls 避免系统 OpenSSL 依赖，default-features=false 关闭 native-tls

## 4. 遇到的问题与解决

### 4.1【设计决策】API Key 配置方式

- 技术方案提到"API Key 配置"但未指定方式。
- S4 用环境变量 `DEEPSEEK_API_KEY`（最简方案，MVP 够用）。
- S5 设置页可加 API Key 输入框，持久化到 SQLite 或配置文件。

### 4.2【设计决策】日期处理不用 chrono

- 项目未引入 chrono，用 Howard Hinnant 的 `days_from_civil` / `civil_from_days` 算法手动算 UTC+8 日期。
- 代码量小、无额外依赖，MVP 阶段足够。如后续需复杂日期操作（周报按周分组），再引入 chrono。

### 4.3【已知】剪贴板兼容性

- 使用 `navigator.clipboard.writeText`，在 Tauri webview 中通常可用。
- 若个别环境不支持，catch 后静默失败。S5 可改用 `@tauri-apps/plugin-clipboard-manager` 插件保证兼容。
